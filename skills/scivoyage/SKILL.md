# SciVoyage Skill

## 用途

将一组旅行照片和对应的中文说明，自动整理并排版成**看起来像论文 Figure 1 的社交媒体组图**。本质是把旅行照片组合成一张有新意、适合发朋友圈/小红书/Instagram 的长图：
- 子图按 `(a)`、`(b)`、`(c)` … 编号
- 每个子图的**中文说明翻译成英文**，放入整体图注中
- 整体底部有 `Fig. 1. XXXXX.` 形式的完整英文图注
- 可加入红色虚线框、箭头、标注等强调元素
- 字体风格与参考图片（黄山徒步图）保持一致
- 风格清晰、信息密度高，既有科研图的仪式感，又有旅行分享的故事感

## 调用方式

用户给出旅行照片和中文解释后，按以下流程执行。

### 1. 收集信息

从用户消息中提取：

- **主题标题**：整张图想表达什么（例如：黄山徒步行程亮点）
- **子图素材**：每张旅行照片的内容和顺序
- **中文子图说明**：用户对每张照片的中文解释（1-2 句话）
- **可选标注**：是否需要红框、虚线、箭头、文字标注（如地图路线、景点名称）
- **输出格式**（默认输出可直接发社交媒体的单张图片）：
  - 图片（PNG/JPG，推荐，适合发朋友圈/小红书/Instagram）
  - Python matplotlib/Pillow 排版脚本（用户想自己调整时使用）
  - Markdown 图文混排
  - HTML 网页
  - LaTeX `subfigure` 代码

> 默认行为：**将中文说明翻译成英文**，并生成英文版整体图注。

### 2. 翻译处理

将用户提供的中文说明按以下规则翻译为英文：

- **保持“科研风图注”语气**：像论文 Figure caption 一样简洁、客观，但不必过于生硬，保留旅行分享的轻松感
- **地名、景点名、人名**保留常用英文译名（如：黄山 → Huangshan，迎客松 → Guest-Greeting Pine，天都峰 → Tiandu Peak）
- **时间、数字、专有名词**直接保留
- 每张子图说明翻译为 1-2 句英文，首字母大写，句末加句点
- 整体图注格式：
  ```
  Fig. 1. {主题英文}. (a) {子图1英文说明} (b) {子图2英文说明} ... (j) {子图N英文说明}.
  ```
- 如果中文说明偏口语（如“这块石头真的绝了”），翻译时润色为适合图注的英文表达（如 "The uniquely shaped rock formation"），但不改变原意

### 3. 布局设计

根据子图数量和重要性，选择以下常见布局之一：

| 子图数 | 推荐布局 | 适用场景 |
|--------|----------|----------|
| 2-3 | 单行等宽 | 对比图、流程图 |
| 4-6 | 2×2 或 2×3 | 论文常用 |
| 7-10 | 不规则网格（上 3 + 下 4 等）| 旅行集锦、综合展示 |
| 地图+照片 | 左上角放地图，其余放照片 | 行程类展示 |

排版原则：
- 重要子图（如路线图、全景）可占更大面积
- 人物合影、地标特写可小一些
- 保持对齐和一致间距
- 使用白色或浅灰背景，黑色边框或细线分隔
- **社交媒体适配**：最终输出为单张竖版长图，宽度建议 1080 px（适合小红书/Instagram），高度根据子图数量和内容灵活调整
- **不强制固定长宽比**：以美观和内容为优先，允许根据照片本身的比例、重要性和视觉重心自由调整子图大小与整体高度

### 美观优先原则

排版时不拘泥于固定网格，重点保证视觉平衡：

- **疏密有致**：避免大面积空白或过度拥挤，子图之间保持统一间距（建议 8-16 px）
- **视觉重心**：最有冲击力的照片（如全景、人物合影、地标特写）可以更大或放在视觉中心
- **对齐与留白**：子图边缘尽量对齐，四周留出适度边距（建议 20-40 px），不要让内容贴边
- **比例协调**：相邻子图长宽比差异过大时，用留白或调整尺寸来平衡，而不是强行拉伸
- **色彩和谐**：保持原片自然色调，红色标记仅作为点缀，不要喧宾夺主
- **呼吸感**：整体图注与图片之间留出足够空间，避免文字紧贴图片

### 4. 样式规范

- **子图编号**：
  - 左上角加粗无衬线字体 `(a)`、`(b)`、`(c)`…，推荐 **Arial Bold** / **Helvetica Bold**
  - 统一使用**固定大小的白色方块背景**（例如 48×40 px），文字在方块中居中
  - 白色方块必须**严丝合缝贴齐各子图的左上角**，不超出图片边界
- **子图说明**：统一放入底部整体图注中，不在单图上重复放置
- **整体图注**：底部左对齐，`Fig. 1.` 使用**加粗衬线字体**（如 **Times New Roman Bold**），后面接描述，使用衬线字体（如 **Times New Roman**），末尾加句点
- **字体一致性**：
  - 编号与图片内标注：无衬线字体（Arial / Helvetica），加粗
  - 图注文字：衬线字体（Times New Roman）
  - 与参考图片 `0ed7fc829c6875461cee53faa078b726.jpg` 的字体风格保持一致
- **强调元素**：
  - 红色实线/虚线框：框选重点区域
  - 红色实线/虚线：连接、引导、标注
  - 红色箭头：指向关键位置
  - 红色文字标签：标注地名、时间、人物；**标签背后不加白色背景**，可用深色描边保证可读性
- **红色标记线宽统一**：所有红色线条（箭头、边框、连接线）使用统一线宽，建议 3 px
- **配色**：以自然色为主，标注色使用红色 `#E53935` 或橙色 `#FB8C00`

### 5. 红色标记使用规范（基于参考图）

参考图片中的红色标记有明确分工，不要滥用。使用前先判断用途：

#### 5.1 粗实线红色箭头 —— 表示方向、路线、流程

- **用途**：在地图、路线图、流程图上标示移动方向或时间顺序
- **样式**：
  - 线宽较粗（约 3-5 px）
  - 实心箭头，箭头较大
  - 颜色：`#D32F2F` 或 `#E53935`
- **示例**：子图 (a) 黄山路线图中，红色粗箭头连接各景点并标注时间（6:00 → 7:20 → ...）
- **适用场景**：
  - 旅行路线图
  - 时间线/行程顺序
  - 视线引导（从 A 点到 B 点）

#### 5.2 红色虚线 —— 表示关联、引导、区域边界

- **用途**：把读者的注意力从某处引导到另一处，或框出一片不规则关注区域
- **样式**：
  - 虚线线段中等长度（约 8-12 px 实线 + 6-8 px 空白）
  - 线宽中等（约 2-3 px）
  - 颜色：`#E53935`
- **示例**：子图 (d) 中，红色虚线从右上角延伸至峡谷区域，再连接红色实线框
- **适用场景**：
  - 全景图中指出局部放大区域
  - 连接标注文字和目标物体
  - 标示视线移动路径

#### 5.3 红色实线矩形框 —— 突出显示关键区域

- **用途**：在复杂画面中框出一个明确的长方形区域，表示“重点看这里”
- **样式**：
  - 实线，线宽 2-3 px
  - 不填充或轻微透明填充
  - 颜色：`#E53935` 或 `#D32F2F`
- **示例**：子图 (d) 中，红色实线框圈出峡谷中的关键山峰群
- **适用场景**：
  - 风景照中框出地标
  - 地图中框出活动范围
  - 合影中框出重要人物/建筑

#### 5.4 红色细箭头 + 红色文字标签 —— 地名/特征标注

- **用途**：在照片中直接标注地名、峰名、建筑名等
- **样式**：
  - 细实线箭头（1.5-2.5 px），箭头较小
  - 箭头从红色文字标签指向目标
  - 文字标签用红色无衬线字体（Arial / Helvetica），加粗
  - 颜色：`#E53935`
- **示例**：子图 (g) 中，"Tiandu Peak" 和 "Lianhua Peak" 两个红色标签通过箭头分别指向对应山峰
- **适用场景**：
  - 地标照片标注山峰/建筑名
  - 合影中标注人物姓名（较少用）
  - 风景照中标注特殊地貌

#### 5.5 实线小框 + 虚线延长线 + 虚线放大图边框 —— 放大细节指引

- **用途**：在全景子图（远景）中框出一块区域，用相邻的单独子图 (g)/(h) 放大展示该细节（近景）
- **样式**（必须严格区分线型）：
  - **远景中的小框**：用红色**实线**矩形框出要放大的区域
  - **延长线**：用红色**虚线**从远景小框的右侧/下侧边角引出，连接到近景放大图
  - **近景放大图边框**：用红色**虚线**矩形框住整个放大子图
  - 三种红色标记的线宽必须一致，建议 3 px
  - 颜色：`#E53935`
- **延长线末端规则**：
  - 虚线延长线的末端必须落在近景放大图**最近的边角上**
  - 例如：放大图放在主图右侧时，延长线从主图小框的右侧上下角分别连到放大图的左上角和左下角
- **布局建议**：
  - 放大子图尽量放在被放大主图的相邻位置（正右方优先，正下方次之）
  - 避免连接线横穿其他子图；如果距离较远，可沿画布边缘或间隙走线
- **示例**：测试图 `test_trip/final_composite.jpg` 中，(a) 峡湾全景左下角用红色实线框出观景台区域，右侧 (g) 展示该区域的放大细节；两条红色实线分别从小框右侧上下角连到 (g) 的左侧上下角；(g) 整体用红色虚线边框包围
- **适用场景**：
  - 风景照中突出人群、建筑、地貌细节
  - 地图中放大显示某个小区域
  - 合影中放大显示某个人或表情

#### 5.6 使用原则

- **克制使用**：每张子图最多 1-2 种红色标记，避免画面杂乱
- **颜色统一**：所有红色标记使用同一红色系（`#E53935` 附近）
- **线宽统一**：所有红色线条（实线框、虚线框、箭头、连接线）使用相同线宽，建议 3 px
- **语义一致**：同一类标记在同一组图中有统一含义（如实线框=放大区域，虚线框=放大图边框）
- **避免遮挡主体**：标记尽量放在天空、地面、植被等次要区域，不要压住人脸或核心景物
- **避免穿图**：连接不同子图的线条尽量走边缘或间隙，不要从其他照片中间穿过
- **与图注配合**：红色标记标出的内容，应在图注中用文字说明

### 7. 代码输出模板

如果用户要可执行的排版代码，提供 Python + matplotlib/Pillow 脚本：

```python
import matplotlib.pyplot as plt
from matplotlib import gridspec
import matplotlib.patches as patches

fig = plt.figure(figsize=(12, 10))
gs = gridspec.GridSpec(3, 3, figure=fig, hspace=0.25, wspace=0.15)

# 示例：不规则布局
ax_a = fig.add_subplot(gs[0, 0])
ax_b = fig.add_subplot(gs[0, 1:])
ax_c = fig.add_subplot(gs[1, 0])
ax_d = fig.add_subplot(gs[1, 1:])

for ax, label in zip([ax_a, ax_b, ax_c, ax_d], ['(a)', '(b)', '(c)', '(d)']):
    ax.text(0.02, 0.98, label, transform=ax.transAxes,
            fontsize=14, fontweight='bold', va='top', color='black',
            bbox=dict(boxstyle='round,pad=0.2', facecolor='white', edgecolor='none'))
    ax.axis('off')

fig.text(0.5, 0.02, 'Fig. 1. {完整图注}', ha='center', fontsize=12, wrap=True)
plt.savefig('output.png', dpi=300, bbox_inches='tight')
```

## 注意事项

- 如果素材图片长宽比差异大，优先用 `object-fit: cover` 或等比例裁剪，避免拉伸变形
- 文字不要压在图片复杂背景上；必要时加半透明黑色/白色衬底
- 子图编号与整体图注中的编号顺序必须一致
- **图注高度必须动态计算**：英文翻译后的图注长度不固定，生成图片前要先计算换行后的实际行数，再确定画布总高度，避免底部文字被截断
- 导出分辨率建议 ≥ 300 DPI，用于论文或印刷
